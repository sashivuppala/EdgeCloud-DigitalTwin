## Option 1: Detailed Post

Built and delivered `EdgeCloud-DigitalTwin`, an end-to-end Python project that simulates an enterprise processing pipeline using an edge-cloud digital twin architecture.

What this project does:

- simulates document and workflow events with queue depth, validation issues, retry counts, transformation latency, publish outcomes, and acknowledgement delays
- injects enterprise pipeline conditions such as malformed XML bursts, retry storms, publication failures, and backlog spikes
- performs low-latency validation and anomaly screening at the edge
- routes workloads dynamically between edge and cloud based on processing time, backlog severity, retry pressure, and complexity
- maintains a cloud-side digital twin state with workflow health metrics and historical trend analysis
- exposes APIs for event ingestion, status, and metrics
- logs events, anomalies, and orchestration decisions into SQLite

Tech stack used:

- Python
- FastAPI
- Pandas
- NumPy
- SQLite
- Streamlit
- Docker

What I liked most about this build:

- clear separation between simulator, edge processing, cloud intelligence, orchestration, and API layers
- realistic operational scenarios such as high latency, edge overload, and anomaly injection
- both technical and stakeholder-friendly documentation for onboarding and demos

This project is a strong prototype for demonstrating how enterprise workflow platforms can balance real-time responsiveness at the edge with richer operational analysis in the cloud.

Happy to connect with anyone working on:

- digital twins
- edge AI
- workflow orchestration
- enterprise integration
- document processing

## Option 2: Shorter Post

Built `EdgeCloud-DigitalTwin`, a complete Python-based simulation of an enterprise workflow platform using an edge-cloud digital twin architecture.

The system:

- generates workflow events for document-heavy processing pipelines
- detects anomalies at the edge
- offloads deeper analysis to the cloud
- dynamically orchestrates workloads based on backlog, retry pressure, and complexity
- exposes monitoring APIs and logs operational metrics

Stack:

- Python
- FastAPI
- NumPy and Pandas
- SQLite
- Streamlit
- Docker

A strong exercise in system design across simulation, edge validation, cloud analysis, orchestration, APIs, and observability.
